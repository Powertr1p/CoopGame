# CoopGame

Кооперативная многопользовательская игра на Unity с сетевой синхронизацией через Mirror.

## Технологический стек

- **Engine**: Unity
- **Networking**: Mirror (библиотека для многопользовательских игр)
- **Language**: C#
- **Physics**: Unity Physics (Rigidbody, CharacterController, HingeJoint)

## Основные механики

### Управление персонажем
- Движение через `CharacterController` (WASD)
- Прыжки с физикой гравитации
- Управление камерой от первого лица (мышь)
- Анимация движения через `Animator`

### Взаимодействие с объектами

#### Двери
- Открытие/закрытие дверей через `HingeJoint`
- Физическое взаимодействие: игрок тянет дверь мышью
- Расчет направления открытия относительно положения игрока
- Ограничение дистанции взаимодействия (2 метра)
- Управление через моторы `JointMotor`

#### Подбор предметов
- Подбор объектов на клавишу E
- Предметы прикрепляются к точке руки игрока
- Бросок предметов с применением физической силы
- Проверка занятости предмета другим игроком

## Сетевая синхронизация

### Архитектура
- **Client-Server** модель через Mirror
- Авторитетный сервер для всех игровых действий

### Синхронизируемые данные

#### Двери (`Door.cs`)
- `[SyncVar] float _syncedVelocity` - скорость движения двери
- `[Command] CmdSetVelocity()` - отправка команды на сервер каждые 0.05 сек
- Hook `OnVelocityChanged()` - применение скорости на всех клиентах
- Синхронизация через `NetworkBehaviour`

#### Предметы (`PickupItem.cs`)
- `[SyncVar] NetworkIdentity _pickedUpBy` - владелец предмета
- `[Server] PickUp()` - серверная логика подбора
- `[Server] Drop()` - серверная логика броска
- Hook `OnPickedUpByChanged()` - обновление состояния на клиентах
- Управление `Rigidbody.isKinematic` для физики

#### Игрок (`PlayerPickup.cs`)
- `[SyncVar] NetworkIdentity _syncHeldObject` - удерживаемый объект
- `[Command] CmdPickupItem()` - команда подбора на сервер
- `[Command] CmdDropItem()` - команда броска на сервер

### Оптимизация трафика
- Throttling обновлений двери (20 Hz)
- Использование `[Client]` атрибута для локальной логики
- `isLocalPlayer` проверки для ввода
